# Estimativa de custo — API Anthropic (ordem de grandeza; conferir preços vigentes em anthropic.com/pricing)
Premissas: redator ~25 matérias/dia, ~6k tokens entrada + 1k saída cada; curador de imagem ~40 imagens/dia, ~2k tokens entrada (imagem+texto) + 100 saída.
Total/dia ≈ 150k+25k tokens (redator) + 80k+4k (curador) ≈ 0,26 M tokens.
Com um modelo da classe Sonnet (~US$3/M entrada, ~US$15/M saída): ≈ US$0,6–1/dia → ~US$20–30/mês.
Com Haiku para curador/triagem: ~US$15–20/mês. Cenário alto (60 matérias/dia): ~US$50–70/mês.
